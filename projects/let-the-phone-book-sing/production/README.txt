Let the Phone Book Sing — timing build route

Core/project scripts run with the toolkit environment (.venv/Scripts/python.exe on this Windows checkout; .venv/bin/python3 on Mac/Linux).

1. Ingest the confirmed master and supplied DAWproject to generated/source/, recording SHA256 in source-manifest.json. Retain the original embedded source WAVs. Generated XML readback and offset measurements are under generated/.
2. prepare_timing.py rebuilds enabled lead/backing masks at master clock from the verified beat-7 origin. Original PCM16 stems are decoded to PCM24 analysis copies; originals are untouched.
3. tools/timeline.py sync projects/let-the-phone-book-sing/project.json imports the exact curve and compiles the musical register. Do not remove timing.zeroBeat or copy timing from another song.
4. Unprompted tools/transcribe_words.py runs in the existing isolated speech interpreter configured in ignored project.local.json. This preserves the toolkit environment; no speech-model package was installed/upgraded for this task. Raw outputs are audio.whisper.raw.json, lead.whisper.raw.json and backing.whisper.raw.json.
5. align_words.py is a retained copy of the existing workbench WhisperX alignment worker (amtw/tools/wordtiming/align.py plus review.html). It uses the existing vevo2 speech environment plus the existing tools/word-timing overlay and cached WAV2VEC2_ASR_BASE_960H model. Invoke it with --audio, --performance lyrics/alignment-plan-v002.json, --out, --runtime and --offset 0 because the audio proxy is already in master time. The --runtime path is machine-local. Retain both lead alignment-v002 and master-crosscheck-v002 evidence. v001 is retained as history.
6. package_timing.py maps spoken units to original display tokens, preserving names/numerals and independent endpoints. It writes timeline.json, CSV/JSON review lists and native build assets. Do not run it over accepted user corrections without merging them first.
7. build_animatic.py uses the pinned installed EffectCraft 0.18.0 MCP server headlessly. It writes the portable native .ecproj and four preview PNGs. It does not modify the user's open editor. effectcraft_session.py is adapted from Together Anyways' saved client. Native media links use assets/ paths; font/license are bundled alongside the master and measured waveform image.
8. validate_animatic.py checks actual native text, lyric layer counts, geometry, page intervals, word-frame bounds, rest-label states and the source master hash. tools/timeline.py validate independently checks the register.
9. Render the native project using the configured EffectCraft CLI (render --project FILE --gpu --out native-picture-v001.mp4 --progress --bitrate 5000 --audio off). Then mux generated/animatic/assets/master.wav directly using ffmpeg: copy video, encode AAC at 256 kbps, pad only the final fractional frame and limit output to 4340/24 seconds. The native project also contains its editable master audio layer.

Final checks: ffprobe confirms 4340 frames at 24 fps and stereo 48 kHz audio. Compare decoded preview audio to the confirmed master at several windows; inspect preview PNGs for text clipping and unwanted overlays. Structural checks do not establish listening approval.
