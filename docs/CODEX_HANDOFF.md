# Handoff: generate the v6 storyboard stills with the OpenAI image model

Written 2026-09-03 for Codex desktop (or any agent with an `OPENAI_API_KEY`)
so the still pass can run unattended. Everything it needs is in this repo;
nothing here requires Google Flow.

## Why this pass exists

"Rivers of Mars" is being re-realized as live-action-style generated
footage: a Wes Anderson take on a 1950s Technicolor science-fiction feature.
Storyboard stills are generated per **setup** (41 setups cover 59 cuts), then
approved stills become the start frame of a short video clip. The owner's
comparison on 2026-09-03 (`docs/STORYBOARD_REVIEW.md`, "Lock comparison")
found that the OpenAI image model gives the preferred look and holds the
lead's face when her likeness photograph is attached. This pass regenerates
every setup there.

## Inputs (all in the repo)

| file | what it is |
|---|---|
| `prompts/stills_manifest.json` | **the job list**: one entry per setup with the full prompt, the reference images to attach, output paths, guards. Generated by `tools/still_manifest.py`; do not hand-edit. |
| `prompts/prompts.md` | the same prompts, human-readable, with the video prompts too |
| `shots/style.md` | the world, the cast lines, the lock block (the contract every prompt ends with) |
| `refs/astronaut_likeness.jpg` | the lead's locked likeness (both twins share this face) |
| `refs/merfolk_likeness_gpt.jpg` | the approved chrome mer-folk school |
| `refs/specimen_ref.jpg` | the helical alien specimen |
| `refs/world_anchor.jpg` | photographic world anchor for non-character shots |

`refs/*.jpg` are out of Git (media). If they are missing on this machine,
stop and ask; do not substitute.

## Procedure

1. Read `prompts/stills_manifest.json`. For each entry, in order:
   - Call the image **edit** endpoint (the one that accepts reference images),
     model `gpt-image-1` or newer, with `refs` attached as the input images
     and `prompt` verbatim. Size `1536x1024`, quality `high`, two outputs.
     If the API offers a 16:9 size use it; otherwise crop `1536x1024` to
     `1536x864` centered.
   - Save as `outputs[0]` and `outputs[1]` (`board/v6/<setup>_a.jpg`,
     `board/v6/<setup>_b.jpg`), JPEG quality 92. Create `board/v6/`.
   - Skip an entry whose two outputs already exist (the run is resumable).
   - On a content-policy refusal or API error, log it to
     `board/v6/_log.md` with the setup name and the message, and continue.
2. Do **not** paraphrase, shorten, or "improve" a prompt. The lock block
   at the end of every prompt is identical on purpose; identical wording
   across shots is the consistency mechanism.
3. Do not generate the video prompts; this pass is stills only.
4. When all entries are done, write `board/v6/_report.md`: count generated,
   count skipped, the failures, total spend if the API reports it.
5. Do not touch `board/frames/`, `board/v2..v5/`, `shots/`, `prompts/`, or
   anything outside `board/v6/`. Do not commit; the owner reviews first.

## Acceptance guards (check before saving; regenerate once if violated)

Each entry carries its own `guards`; the universal ones:

- No text, captions, titles or lettering anywhere in the frame.
- Photographed, never illustrated. Miniatures, matte paintings and stage
  work are fine; drawn or painted looks are rejects.
- Character shots: the face matches `refs/astronaut_likeness.jpg`; no
  eyewear; the plain smooth brushed-silver suit with one riveted collar
  ring and nothing else on it.
- Mer-folk shots: exactly one large round eye centered in each face, no
  second eye, no nose; a fish tail below the waterline and no legs; all
  identical to the attached school.
- Non-character shots: no people. Only the two twin sisters and the
  mer-folk ever appear anywhere in this film; no extras, no spacemen.

Judge by eye if you can view the image; otherwise trust the prompt and let
the owner cull from the contact sheet.

## Cost and time (tell the owner before starting)

82 images at `high` quality on `gpt-image-1` is on the order of USD 15 to 25
of API spend (the API is billed separately from a ChatGPT subscription).
Sequential calls take roughly one minute each; parallelize four at a time
if the account's rate limit allows.

## After the pass (owner side, not Codex)

Keepers are copied into `board/frames/<setup>_p.jpg` / `_q.jpg`, then
`python tools/board_contact.py` rebuilds `board/contact.html` and
`python tools/blender_comp.py --variant-order p,q,n,m,f,e,d,c,b,a` renders
the animatic with the new stills on top.
